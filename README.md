# 桌面办公助手

一个用 Python + Tkinter 编写的本地桌面助手，可以添加待办事项，并在到期前弹窗提醒。程序不写注册表，所有数据都保存在本地 JSON 文件中，绿色便携。

## 功能

- 添加、编辑、删除待办事项
- 截止时间通过下拉菜单选择（年、月、日、时、分），无需手动输入
- 设置优先级、标签和备注
- 支持提前提醒（0 分钟到提前 24 小时）
- 到期自动弹窗提醒，可推迟 5 或 15 分钟
- 语音播报提醒：用 Windows 语音朗读“请注意，还有多久到期”
- 每条事项可单独选择是否语音播报，设置里可一键测试语音
- 设置菜单新增“语音音色”选择，可切换系统里不同的中文/英文语音
- 每日定时提醒：默认每天 20:00 汇总未完成事项，弹窗并语音播报
- 语音转文字：按 F9 开始/停止录音，讯飞语音听写，结果自动复制到剪贴板并显示在右侧面板
- 工具菜单内置“批量解压工具”（unzip_qian），支持 zip/tar/gz/bz2/xz 批量解压
- 工具菜单内置“Excel批量检测工具”：模糊搜索内容、统计个数和位置、查找大于/小于/范围内的数值，结果可导出 CSV
- 已完成事项标灰，过期事项标红
- 按标题、标签、备注即时搜索，可隐藏已完成
- 完整本地日志：记录启动、增删改、提醒、语音播报、设置修改和异常
- 数据保存在程序目录下的 `data\todos.json`

语音播报使用 Windows 自带的 SAPI 语音引擎，不需要额外安装软件；如果系统没有安装中文语音包，会使用系统默认语音朗读。
在“设置”菜单或工具栏的“设置”里，可以下拉切换音色，并立即点击“测试语音”试听。
每日提醒的时间也可以在“设置”里修改（默认 20:00），到点后会汇总所有未完成事项，弹出提醒窗口并语音朗读。

## 语音识别

工具栏“语音转文字”按钮或全局快捷键 F9 可开始/停止录音；识别完成后文本会自动复制到剪贴板，同时显示在右侧“语音识别”面板，并写入 `data\speech\YYYY-MM-DD.txt` 和日志文件。

讯飞账号密钥放在程序目录下的 `asr_config.json`，可以直接编辑；打包后的 exe 会把这个文件一并复制到 `dist` 目录。

## 直接运行源码

需要 Python 3.10 或更高版本（自带 Tkinter）：

```bat
python desktop_assistant.py
```

## 打包成 exe

双击 `build.bat`，脚本会自动安装 PyInstaller 并生成：

```text
dist\桌面办公助手.exe
```

也可以手动执行：

```bat
python -m pip install -r requirements.txt
python build.py
```

生成的是单个 exe 文件，可以复制到任意 Windows 电脑上直接运行。首次启动后，程序会在 exe 同目录创建 `data\todos.json` 保存数据；如果该目录不可写，会自动改用 `我的文档\桌面办公助手数据`。

## 数据说明

- 数据文件：`data\todos.json`
- 日志文件：`data\logs\desktop_assistant.log`，每天自动滚动，保留最近 14 天
- 设置界面里有“打开日志目录”按钮，可快速查看日志
- 备份机制：如果数据文件损坏，会自动改名为 `todos.corrupt.bak`，不会崩溃
- 不写入注册表，卸载只需删除整个文件夹
